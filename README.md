# Bo-Kaap Kombuis

## Project Overview

Bo-Kaap Kombuis is a restaurant website project designed to showcase Cape Malay cuisine and the cultural heritage of the Bo-Kaap. The website provides visitors with information about the restaurant, its menu, food and cultural atmosphere, as well as booking and contact options.

## Website Purpose

The purpose of this website is to provide an informative and user-friendly online presence for Bo-Kaap Kombuis. It allows visitors to:

* Learn about Bo-Kaap Kombuis and its cultural background.
* View the restaurant's Cape Malay food menu.
* Explore photographs in the gallery.
* Submit a booking or enquiry.
* Find contact information.

## Website Pages

The website consists of the following pages:

* **Home** – Introduces Bo-Kaap Kombuis and highlights the restaurant experience.
* **About Us** – Provides information about the restaurant and its cultural connection.
* **Menu** – Displays Cape Malay food and menu information.
* **Gallery** – Showcases food, cultural and restaurant images.
* **Booking** – Allows visitors to submit a booking enquiry.
* **Contact** – Provides contact information for the restaurant.

## Technologies Used

The website was developed using:

* **HTML5** – Used to create the structure and content of the web pages.
* **CSS3** – Used for styling, layout, colours, typography and responsive presentation.
* **JavaScript** – Used to provide interactive functionality, including the booking enquiry confirmation.
* **Git and GitHub** – Used for version control and storing the project repository.

## Images and Media

The website uses images to represent Cape Malay food, the restaurant environment, the Bo-Kaap cultural atmosphere and the gallery. Images are organised into separate folders within the Images directory.

## JavaScript Functionality

JavaScript is used on the booking page to process the booking enquiry form. After the required information is submitted, the website displays a confirmation message thanking the visitor and confirming that the booking enquiry has been received.
