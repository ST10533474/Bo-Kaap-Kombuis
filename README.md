## Project Overview

Bo-Kaap Kombuis is a restaurant website project designed to showcase Cape Malay cuisine and the cultural heritage of the Bo-Kaap. The website provides visitors with information about the restaurant, its menu, food, cultural atmosphere, booking options, enquiries and contact details.

The website was developed as a multi-page website using HTML5, CSS3 and JavaScript. Git and GitHub were also used for version control and project submission.

## Website Purpose

The purpose of the website is to provide Bo-Kaap Kombuis with an informative, attractive and user-friendly online presence.

The website allows visitors to:

* Learn about Bo-Kaap Kombuis and its cultural background.
* View information about Cape Malay cuisine and menu options.
* Explore photographs of food and the restaurant.
* Submit a booking request.
* Send an enquiry or general message.
* Find the restaurant's contact information.
* Navigate between the different sections of the website easily.

## Website Pages

The website consists of the following pages:

### Home

Introduces Bo-Kaap Kombuis and highlights the restaurant experience, Cape Malay cuisine and links to other sections of the website.

### About Us

Provides information about the restaurant, its cultural connection to the Bo-Kaap and its Cape Malay heritage.

### Menu

Displays Cape Malay food and menu options available at the restaurant. JavaScript category filters allow visitors to filter menu items.

### Gallery

Showcases food, restaurant and cultural images. A lightbox feature allows visitors to view gallery images in a larger format.

### Booking

Allows visitors to submit a booking request through an online form with input validation.

### Enquiry

Allows visitors to submit questions or enquiries about the restaurant using a validated enquiry form.

### Contact

Provides restaurant contact information and a form for visitors to send general messages.

## Forms and Functionality

The website includes booking, enquiry and contact forms.

JavaScript validation is used to check that visitors provide the required information before submitting the forms.

The enquiry and contact forms use email preparation functionality to open an email message containing the visitor's submitted information. Visitors must send the prepared email from their email application.

The menu filtering feature allows visitors to view menu items by category, while the gallery lightbox allows visitors to view images in a larger format.
